# Materi panitia GENOHACK

Transkripsi materi bootcamp, daftar peserta, dan detail operasional panitia tidak didistribusikan dalam snapshot produk publik. Hak cipta tetap pada penyelenggara. Tim memiliki salinan referensi lokal yang diabaikan Git. Gunakan kanal resmi panitia untuk memperoleh dokumen aslinya.

Ringkasan persyaratan yang ditulis tim: [Competition requirements](../docs/COMPETITION_REQUIREMENTS.md). Penghapusan dari snapshot ini tidak menghapus salinan pada riwayat Git lama.
