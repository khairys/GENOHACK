# Roadmap setelah MVP

| Periode | Tujuan | Bukti sebelum lanjut |
|---|---|---|
| Segera / hackathon | Wawancara nyata, review pakar, konfirmasi kontribusi, latihan dan submission | Catatan berizin, log waktu, penerimaan unggahan |
| Bulan 1–3 | Kohort Bali independen dan referensi ancestry yang tepat; data pedigree/kinship | Hak akses, metadata, desain grouped validation dan calibration set |
| Bulan 4–6 | Freeze panel dan ambang pada data pengembangan, validasi eksternal tanpa tuning | MAE/calibration, sensitivitas/spesifisitas/subgroup, kegagalan yang dilaporkan |
| Bulan 7–9 | Probe/strand/assembly review dan studi assay | Call rate, repeatability, dropout dan penawaran biaya nyata |
| Bulan 10–12 | Pilot prospektif bersama institusi pembibitan | Workflow, approval/budget, biaya terukur, kemauan membayar dan keputusan penggunaan |

Gates: hentikan klaim assay bila probe/QC gagal; jangan memakai threshold oracle S1 untuk keputusan breeding. SaaS/langganan hanya setelah penggunaan berulang terbukti. Ask: akses kohort, reviewer genetika populasi, mitra assay dan introduksi calon pembeli. Belum ada komitmen mitra atau pendanaan yang diklaim.
