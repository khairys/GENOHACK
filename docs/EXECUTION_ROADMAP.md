## Scope cuts if time is lost

Drop decorative UI, additional panel sizes, and public hosting polish first. Keep checksum verification, source provenance, equal-size baselines, train/test separation, limitations, local demo, and a clear pitch. Never replace absent validation with simulated evidence or an invented customer claim.

## Current state at implementation

Repository evidence did not include customer interviews, a lab partner, assay performance, or a purchase commitment. The code now produces an in-silico research prototype. Human validation and wet-lab work remain team activities that require real participants and a collaborating laboratory.
